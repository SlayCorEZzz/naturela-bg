# Naturela

Нов сайт на **naturela-bg.com** — производител на електронни контролери и
терморегулатори, Варна, от 1994 г.

Съдържанието е свалено веднъж от стария сайт и живее в този проект: страниците не
зареждат нищо от там и не препращат натам.

## Адресите на стария сайт са запазени

Всеки публикуван адрес продължава да работи, със същата наклонена черта накрая.

| Адрес | Страница |
| --- | --- |
| `/`, `/bg/`, `/en/` | начална |
| `/bg/kategorii/` | категории продукти |
| `/bg/products/` | целият каталог, с търсене (`?word=` както досега) |
| `/bg/products/<категория>/` | продуктово направление |
| `/bg/product/<номер-модел>/` | продукт: галерия, описание, документация |
| `/bg/useful/`, `/bg/useful-more/<статия>/` | Полезно |
| `/bg/pages/<страница>/` | За нас, История, Условия, Лични данни |
| `/bg/contacts/?url=<продукт>` | контакти с попълнено запитване |

Рутерът е с `trailingSlash: "always"` (`src/router.tsx`), затова линковете, които
сайтът генерира, изглеждат точно като старите.

## Структура

```
src/data/          съдържанието: продукти, категории, статии, страници
                   (свалено веднъж от стария сайт — оттук нататък се редактира тук)
src/components/site/  хедър, футър, галерия, карти, търсене
src/routes/$lang/  езиковият префикс, който старият сайт въведе (/bg/, /en/)
public/media/      снимките от стария сайт, конвертирани веднъж
public/n/          лого, клиенти, икони на категориите
```

`logo.png` е бял (за тъмен фон), `logo-ink.png` е тъмен (за светла лента) — двата
са от една и съща палитра, прекодирана от оригинала.

## Разработка

```sh
npm i
npm run dev
```

`npm run build` прави production build, `npm run lint` проверява кода.

## Документация (PDF)

Ръководствата за продуктите са ~135 MB и линковете сочат към сегашния файлов
сървър, за да работят днес. Когато той ще бъде спрян:

```sh
node scripts/fetch-docs.mjs
```

Скриптът ги сваля в `public/media/docs/` и пренасочва линковете към локалните
копия.

## Запитвания от формата

Формата в `/bg/contacts/` отваря пощенската програма на посетителя с попълнено
запитване. За изпращане от сървъра трябва да се добави endpoint (проектът вече е
свързан със Supabase).
